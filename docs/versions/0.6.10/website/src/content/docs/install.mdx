---
title: Install Innov
description: Install, update, and verify Innov on Linux, macOS, and Windows beta.
---

Innov ships stable binaries for Linux and macOS. Native Windows support is preview-only beta.

## Install

On Linux or macOS, run:

```bash
curl -fsSL https://innov.dev/install.sh | sh
```

On Windows preview beta, install the preview channel:

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://innov.dev/install.ps1 | iex"
```

The installer downloads the right release binary for your platform and places it on your PATH. The Windows installer defaults to preview, writes that channel to Innov's config, uses versioned install folders, and updates a `current` junction, so updates do not need to overwrite a running `innov.exe`.

## Install with Homebrew

If you already use Homebrew:

```bash
brew install innov
```

## Install with mise

If you already use mise:

```bash
mise use -g innov
```

If mise reports `innov not found in mise tool registry`, update mise and retry. Older mise versions predate the Innov registry entry; `mise use -g github:Duke0503/cli` works as a temporary fallback.

## Verify

Start Innov:

```bash
innov
```

If your shell cannot find `innov`, restart the terminal or check that the install directory is on your PATH.

## Update

Innov checks for new releases and notifies you in the app. You can update manually:

```bash
innov update
```

`innov update` is for installs managed by Innov's own installer. Homebrew, mise, and Nix installs are updated through those package managers instead.

On Linux and macOS, Innov uses the stable update channel by default. To opt into preview builds from `master`, set the channel:

```bash
innov channel set preview
```

Switch Linux and macOS direct installs back to stable the same way:

```bash
innov channel set stable
```

For direct installs, changing channels also checks that channel and installs its latest binary. If that update fails, run `innov update` to retry from the configured channel.

Preview builds are GitHub prereleases published from the current development branch. They are useful when you want fixes before the next stable release, but they can regress. Homebrew, mise, and Nix installs do not use the preview channel.

Windows beta builds are preview-only for now. `innov channel set stable` is rejected on Windows until stable Windows releases are available.

By default, `innov update` installs the new binary and leaves compatible running sessions alone. If an update changes Innov's client/server protocol, Innov asks whether to stop the old server after installing. Stop the old server to use the new version. Stopping exits pane processes. For the default session, run `innov server stop`, then run `innov` again. For a named session, run `innov session stop <name>`, then run `innov session attach <name>` again.

To opt into experimental live server handoff for supported running sessions, run:

```bash
innov update --handoff
```

Live handoff does not apply to Homebrew, mise, or Nix package-manager updates. For those installs, update with the package manager, then restart that Innov session when you are ready to use the new server. If a running session still uses the old server, stop it with `innov server stop` or `innov session stop <name>`, then run Innov again.

## Install with Nix

If you already use Nix, Innov provides a flake that builds Innov from source:

```bash
nix run github:Duke0503/cli/v0.x.y
nix build github:Duke0503/cli/v0.x.y
nix profile install github:Duke0503/cli/v0.x.y
```

Replace `v0.x.y` with the latest release tag. You can omit the tag to track `master`, but release tags are recommended for normal installs.

The flake also exposes a development shell:

```bash
nix develop github:Duke0503/cli
```

Update through the same Nix workflow you used to install Innov. For a profile install, list your profile entries and upgrade the Innov entry:

```bash
nix profile list
nix profile upgrade <index-or-name>
```

If Innov is an input in your own flake, update that input and rebuild your system, Home Manager, or development environment:

```bash
nix flake update innov
```

## Download manually

You can also download a binary from [GitHub releases](https://github.com/Duke0503/cli/releases).

Choose the asset that matches your system:

| System | Asset |
| --- | --- |
| Linux x86_64 | `innov-linux-x86_64` |
| Linux aarch64 | `innov-linux-aarch64` |
| macOS Intel | `innov-macos-x86_64` |
| macOS Apple silicon | `innov-macos-aarch64` |

On Linux or macOS, make it executable and move it somewhere on your PATH.

```bash
chmod +x innov-linux-x86_64
mv innov-linux-x86_64 ~/.local/bin/innov
```

### Windows beta downloads

Windows binaries are published only on preview releases while native Windows support is in beta. Use the preview installer above for normal testing, or download the Windows asset from a preview GitHub prerelease:

| System | Asset |
| --- | --- |
| Windows x86_64 beta | `innov-windows-x86_64.exe` |

## Requirements

Stable Innov releases support Linux and macOS. Native Windows builds are preview-only beta releases; see [Windows beta](/docs/windows-beta/) for supported workflows and known limitations.
