title: CLI reference
description: Innov commands for sessions, workspaces, tabs, panes, agents, waits, integrations, and status.
---

Innov’s CLI talks to the running server over the same local socket API used by integrations and agents.

Most commands print JSON responses. Use them from scripts when you want deterministic automation.

## Launch and status

```bash
innov                         # launch or attach to the default session
innov --session work          # launch or attach to a named session
innov --remote workbox        # attach through SSH, using local keybindings
innov --remote workbox --remote-keybindings server
innov --no-session            # single-process escape hatch
innov --default-config        # print default config
innov update                  # download and install the latest version
innov --version               # print version
```

Status commands:

```bash
innov status
innov status server
innov status client
```

## Server

```bash
innov server
innov server stop
innov server reload-config
```

`innov server` runs the headless server explicitly. Use it for supervised or service-style setups. `reload-config` applies reloadable settings without restarting panes.

## Sessions

```bash
innov session list [--json]
innov session attach <name>
innov session stop <name> [--json]
innov session delete <name> [--json]
```

Use `default` as the session name when you need to stop the default session explicitly.

## Workspaces

```bash
innov workspace list
innov workspace create [--cwd PATH] [--label TEXT] [--focus] [--no-focus]
innov workspace get <workspace_id>
innov workspace focus <workspace_id>
innov workspace rename <workspace_id> <label>
innov workspace close <workspace_id>
```

Create a workspace without stealing focus:

```bash
innov workspace create --cwd ~/project --label api --no-focus
```

## Worktrees

```bash
innov worktree list [--workspace ID | --cwd PATH] [--json]
innov worktree create [--workspace ID | --cwd PATH] [--branch NAME] [--base REF] [--path PATH] [--label TEXT] [--focus] [--no-focus] [--json]
innov worktree open [--workspace ID | --cwd PATH] (--path PATH | --branch NAME) [--label TEXT] [--focus] [--no-focus] [--json]
innov worktree remove --workspace ID [--force] [--json]
```

Worktrees are normal Innov workspaces with Git checkout provenance. `worktree create` creates a Git worktree checkout, opens it as a workspace, and groups it with the parent repo workspace. Without `--path`, Innov creates the checkout under `<worktrees.directory>/<repo>/<branch-slug>`.

`workspace close` closes Innov state only. `worktree remove` is the explicit checkout deletion path; it runs `git worktree remove`, never deletes the branch, and requires `--force` when Git refuses a dirty checkout.

## Tabs

```bash
innov tab list [--workspace <workspace_id>]
innov tab create [--workspace <workspace_id>] [--cwd PATH] [--label TEXT] [--focus] [--no-focus]
innov tab get <tab_id>
innov tab focus <tab_id>
innov tab rename <tab_id> <label>
innov tab close <tab_id>
```

## Panes

```bash
innov pane list [--workspace <workspace_id>]
innov pane get <pane_id>
innov pane rename <pane_id> <label>|--clear
innov pane split <pane_id> --direction right|down [--cwd PATH] [--focus] [--no-focus]
innov pane close <pane_id>
```

Read output:

```bash
innov pane read <pane_id> [--source visible|recent|recent-unwrapped] [--lines N]
innov pane read <pane_id> --source visible --ansi
innov pane read <pane_id> --source recent-unwrapped --lines 120
```

Send input:

```bash
innov pane send-text <pane_id> <text>
innov pane send-keys <pane_id> <key> [key ...]
innov pane run <pane_id> <command>
```

`pane run` submits text plus Enter atomically. Prefer it over `send-text` plus `send-keys Enter` for commands.

Report agent state from custom hooks:

```bash
innov pane report-agent <pane_id> \
  --source ID \
  --agent LABEL \
  --state idle|working|blocked|unknown \
  [--message TEXT] \
  [--custom-status TEXT] \
  [--seq N]
```

## Agents

```bash
innov agent list
innov agent get <target>
innov agent read <target> [--source visible|recent|recent-unwrapped] [--lines N] [--format text|ansi] [--ansi]
innov agent send <target> <text>
innov agent rename <target> <name>|--clear
innov agent focus <target>
innov agent wait <target> --status <idle|working|blocked|unknown> [--timeout MS]
innov agent attach <target> [--takeover]
innov agent start <name> [--cwd PATH] [--workspace ID] [--tab ID] [--split right|down] [--focus|--no-focus] -- <argv...>
```

Agent targets can be terminal IDs, unique agent names, detected or reported agent labels, or legacy pane IDs. Names and labels are agent identities. Terminal IDs and legacy pane IDs are low-level escape hatches.

`agent read` reads the resolved terminal stream. `agent send` writes literal text to that stream. `agent get`, `agent focus`, `agent wait`, and `agent attach` require the resolved terminal to have agent identity. `agent rename` can assign that identity.

Use `pane send-text`, `pane send-keys`, `pane run`, and `terminal attach` for ordinary terminals, servers, tests, shells, or low-level terminal control. Use `pane run` when you want to submit a command with Enter.

## Direct terminal attach

```bash
innov terminal attach <terminal_id> [--takeover]
```

Detach from direct attach with `ctrl+b q`. Send literal `ctrl+b` with `ctrl+b ctrl+b`.

## Waits

Wait for output in a pane:

```bash
innov wait output <pane_id> --match <text> [--source visible|recent|recent-unwrapped] [--lines N] [--timeout MS] [--regex] [--raw]
```

Wait for pane agent state:

```bash
innov wait agent-status <pane_id> --status <idle|working|blocked|done|unknown> [--timeout MS]
```

Use `wait output` for normal commands and servers. Use `wait agent-status` for coding agents.


## Read sources

| Source | Meaning |
| --- | --- |
| `visible` | Current rendered screen. Best for UI feedback loops. |
| `recent` | Recent scrollback with terminal wrapping. |
| `recent-unwrapped` | Recent scrollback without soft wrapping. Best for logs. |

## Environment variables

| Variable | Purpose |
| --- | --- |
| `INNOV_CONFIG_PATH` | Override the config file path. |
| `INNOV_SESSION` | Select a named session for CLI commands. |
| `INNOV_SOCKET_PATH` | Low-level socket path override. |
| `INNOV_LOG` | Set log filter, for example `INNOV_LOG=innov=debug`. |
| `INNOV_DISABLE_SOUND` | Disable sound playback even when sound notifications are enabled. |
