---
title: Install Innov
description: Install, update, and verify Innov on Linux and macOS.
---

Innov ships as a single binary for Linux and macOS.

## Install

Run the installer:

```bash
curl -fsSL https://innov.dev/install.sh | sh
```

The installer downloads the right release binary for your platform and places it on your PATH.

## Verify

Start Innov:

```bash
innov
```

If your shell cannot find `innov`, restart the terminal or check that the install directory is on your PATH.

## Update

Innov checks for new releases and notifies you in the app. You can update manually:

```bash
innov update
```

## Install with Nix

If you already use Nix, Innov provides a flake that builds Innov from source:

```bash
nix run github:Duke0503/cli/v0.x.y
nix build github:Duke0503/cli/v0.x.y
nix profile install github:Duke0503/cli/v0.x.y
```

Replace `v0.x.y` with the latest release tag. You can omit the tag to track `master`, but release tags are recommended for normal installs.

The flake also exposes a development shell:

```bash
nix develop github:Duke0503/cli
```

Update through the same Nix workflow you used to install Innov. For a profile install, list your profile entries and upgrade the Innov entry:

```bash
nix profile list
nix profile upgrade <index-or-name>
```

If Innov is an input in your own flake, update that input and rebuild your system, Home Manager, or development environment:

```bash
nix flake update innov
```

## Download manually

You can also download a binary from [GitHub releases](https://github.com/Duke0503/cli/releases).

Choose the asset that matches your system:

| System | Asset |
| --- | --- |
| Linux x86_64 | `innov-linux-x86_64` |
| Linux aarch64 | `innov-linux-aarch64` |
| macOS Intel | `innov-macos-x86_64` |
| macOS Apple silicon | `innov-macos-aarch64` |

Make it executable and move it somewhere on your PATH.

```bash
chmod +x innov-linux-x86_64
mv innov-linux-x86_64 ~/.local/bin/innov
```

## Requirements

Innov supports Linux and macOS. Native Windows support is not available yet; use Innov inside WSL for now.
